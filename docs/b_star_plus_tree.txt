BSP_tree — это шаблонный ассоциативный контейнер, реализующий структуру B*+ дерева (B-Star-Plus tree). Класс спроектирован для эффективного хранения, поиска и модификации пар "ключ-значение". Данные хранятся исключительно в листовых узлах (терминальных), которые связаны в однонаправленный список для быстрого диапазонного поиска (Range Queries). Внутренние узлы используются только для маршрутизации.

ШАБЛОННЫЕ ПАРАМЕТРЫ
• tkey: Тип ключа (должен поддерживать копирование/перемещение и сравнение).
• tvalue: Тип хранимого значения.
• compare: Функтор сравнения ключей (по умолчанию std::less). Дерево приватно наследуется от компаратора для оптимизации пустого базового класса (EBO).
• t: Параметр степени дерева (по умолчанию 5). Определяет вместимость узлов:

Минимальное число ключей: t - 1

Максимальное число ключей: 2t - 1

ОСНОВНЫЕ ТИПЫ (АЛИАСЫ)
• tree_data_type: std::pair<tkey, tvalue> — изменяемая пара данных.
• value_type: std::pair<const tkey, tvalue> — константная пара для выдачи пользователю, защищающая ключ от изменения, чтобы не нарушить структуру индекса.
• bsptree_iterator: Итератор чтения/записи (категория std::forward_iterator_tag).
• bsptree_const_iterator: Итератор только для чтения.

ВНУТРЕННЯЯ СТРУКТУРА (УЗЛЫ)
Узлы не хранят указатель на родителя, проход вверх при балансировке осуществляется через локальный std::stack.
• bsptree_node_term (Лист): Сохраняет элементы в boost::container::static_vector. Содержит указатель _next на следующий лист (связный список).
• bsptree_node_middle (Внутренний узел): Хранит массив ключей-разделителей и массив указателей на дочерние узлы (bsptree_node_base*).

УПРАВЛЕНИЕ ПАМЯТЬЮ И ИНИЦИАЛИЗАЦИЯ
Дерево работает через пользовательский аллокатор (pp_allocator). Выделение памяти под разные типы узлов реализуется через механизм std::allocator_traits::rebind.

Конструкторы:
• BSP_tree() — базовый конструктор пустого дерева.
• BSP_tree(iterator begin, iterator end) — создание дерева из диапазона итераторов другой коллекции.
• BSP_tree(std::initializer_list) — создание через список инициализации (например: {{1, "a"}, {2, "b"}}).

Правило пяти (Rule of Five):
• BSP_tree(const BSP_tree&) / operator=(const BSP_tree&) — глубокое копирование всего дерева (O(N*logN)).
• BSP_tree(BSP_tree&&) / operator=(BSP_tree&&) — перемещение за O(1) с кражей указателя на корень.
• ~BSP_tree() — каскадное удаление узлов через внутренний стек (без рекурсии, защита от Stack Overflow).

ДОСТУП К ЭЛЕМЕНТАМ (ОБРАЩЕНИЕ)
• tvalue& at(const tkey& key)
Возвращает ссылку на значение по ключу. Если ключ не найден, выбрасывает std::out_of_range. Имеет const-перегрузку.

• tvalue& operator[](const tkey& key)
Возвращает ссылку на значение. Если ключ не существует, создает новый элемент с дефолтным значением типа tvalue и возвращает ссылку на него. (Поддерживает move-семантику для rvalue-ключей).

ПОИСК И ДИАПАЗОНЫ (LOOKUP)
• bsptree_iterator find(const tkey& key)
Асимптотика: O(log N). Ищет элемент по точному совпадению ключа. Возвращает end(), если элемент не найден.

• bsptree_iterator lower_bound(const tkey& key)
Возвращает итератор на первый элемент, ключ которого БОЛЬШЕ ИЛИ РАВЕН искомому (>=).

• bsptree_iterator upper_bound(const tkey& key)
Возвращает итератор на первый элемент, ключ которого СТРОГО БОЛЬШЕ искомого (>).

• bool contains(const tkey& key) const
Удобная обертка над find(). Возвращает true, если ключ есть в дереве.

• size_t size() const
Возвращает кэшированное количество элементов в дереве (O(1)).

• bool empty() const
Возвращает true, если дерево не содержит элементов.

МОДИФИКАЦИЯ ДЕРЕВА
• std::pair<bsptree_iterator, bool> emplace(Args&&... args)
Конструирует элемент in-place из переданных аргументов (без лишнего копирования). Если элемент с таким ключом уже есть, вставка отменяется (возвращает false). Если узел переполняется, происходит процедура Split (разделение узла).

• std::pair<bsptree_iterator, bool> insert(const tree_data_type& data)
Делегирует вставку методу emplace. (Поддерживает move-семантику).

• bsptree_iterator insert_or_assign(const tree_data_type& data)
Если ключ найден — обновляет значение (assign). Если ключа нет — вставляет новый элемент. (Есть перегрузка emplace_or_assign).

• bsptree_iterator erase(const tkey& key)
Удаляет элемент по ключу. Сдвигает вектор внутри листа. Возвращает валидный итератор на элемент, СЛЕДУЮЩИЙ за удаленным (безопасно проскакивая пустые листья, если они образовались).

• bsptree_iterator erase(bsptree_iterator pos)
Удаление по итератору.

• bsptree_iterator erase(bsptree_iterator beg, bsptree_iterator en)
Удаление диапазона. Безопасно собирает ключи перед удалением, чтобы избежать инвалидации итераторов при проходе.

• void clear() noexcept
Полностью очищает дерево, деаллоцируя все узлы, и сбрасывает размер в 0.

ИТЕРАТОРЫ И ОБХОД
Итераторы поддерживают операторы *, ->, ++, ==, !=.
Оператор инкремента (operator++) автоматически обрабатывает переход к следующему листовому узлу через указатель _next, игнорируя образовавшиеся пустые листья.

• begin() / cbegin()
Спускается по левому краю дерева до самого первого терминального узла и возвращает итератор на нулевой элемент.

• end() / cend()
Представляет собой нулевой итератор (узел = nullptr, индекс = 0). Обозначает конец контейнера.
